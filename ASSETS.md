# Dog record labels

`public/assets/dog-labels.png` is a transparent sprite sheet created with the built-in image generation tool from the user-supplied `IMG_7368.PNG`. The three equal-width cells are displayed separately with CSS, preserving the supplied ears/eyes/mouth pose concept. The generated cleanup is an interpretation of the original drawing, not a pixel-identical extraction.

Prompt: "Use case: background-extraction. Edit target: attached original three blue hand-drawn dogs. Produce ONE transparent PNG sprite sheet containing exactly these three original dogs, one per equal-width cell arranged horizontally, ears-covered on left, eyes-covered center, mouth-covered right. Preserve their distinctive original blue shapes, thin black hand-drawn outlines, poses, eyes, tails and feet as faithfully as possible. Remove all yellow background, including enclosed spaces between arms and head; genuinely transparent alpha. Separate the dogs so no neighboring dog intrudes into another cell. Full figures, unclipped feet tails and ears, equal scale, each centered in its own cell with 10% transparent margins. Canvas 1536x1024 landscape. No vinyl records, no text, no shadows, no new styling or added details. This sprite will be cropped into three independent record label illustrations by CSS."

The vinyl stack extends the existing CSS record treatment. Only grooves rotate; labels stay upright. Selecting a rear record brings it forward; selecting the front record cycles. Arrow keys select adjacent records. Motion pauses when offscreen, hidden, or behind a dialog, and respects reduced motion.
